## 🏆 Principais Projetos

### 1. Sistema de Controle de Estoque

**Repositório:** `projetos-completos/controle-estoque/`
**Tecnologias:** Java, Swing, JDBC, MySQL
**Duração:** ~2 meses (2º Semestre)
**Status:** ✅ Completo e Funcional

#### Descrição
Sistema completo de gerenciamento de estoque com interface gráfica. Aplicação desktop robusta para registrar produtos, gerenciar quantidades, gerar relatórios e manter histórico de movimentações.

#### Features Implementadas
- ✅ CRUD completo de produtos (Create, Read, Update, Delete)
- ✅ Controle de quantidade em tempo real
- ✅ Histórico completo de transações
- ✅ Relatórios exportáveis (PDF/Excel)
- ✅ Sistema de autenticação de usuário
- ✅ Interface intuitiva com Swing
- ✅ Validação de dados em múltiplos níveis
- ✅ Tratamento robusto de erros

#### O que Aprendi
- Desenvolvimento profissional de interfaces gráficas
- Integração com banco de dados relacional
- Padrão arquitetural MVC
- Validação e tratamento de exceções
- User experience design
- Performance e otimização
