## 🚀 Como Usar

### Clonar o repositório
```bash
git clone https://github.com/UandersonSoulza/Projetos-do-SENAI-e-Atividades.git
cd Projetos-do-SENAI-e-Atividades
```

### Navegar até um projeto específico
```bash
# Projetos Java
cd projetos-completos/controle-estoque/
javac -d out src/**/*.java
java -cp out Main

# Projetos Web
cd projetos-completos/portal-primeiro-passo/
# Abrir no navegador ou servir localmente
python -m http.server 8000
```
