## Sobre

Este repositório reúne projetos feitos durante o curso técnico no SENAI e atividades práticas. Além dos projetos acadêmicos, este portfólio também representa experiências práticas aplicadas em ambiente corporativo, incluindo implantação de aplicações web utilizando Supabase, Vercel e integração com domínio próprio.

O objetivo é demonstrar habilidades em POO, arquitetura MVC, padrão DAO, CRUD, modelagem de banco de dados e desenvolvimento de interfaces desktop e web, organizado como um portfólio profissional para recrutadores.

## Destaques do portfólio

## Como executar (guia rápido)

- Java (Swing)
  - Requisitos: JDK 11+ (ou versão usada no projeto), MySQL (se necessário)
  - Executar: abrir o projeto em IDE (IntelliJ/Eclipse) e rodar a classe com main ou gerar jar:
    - mvn package (se Maven) -> java -jar target/app.jar

- Python (CustomTkinter)
  - Requisitos: Python 3.8+, pip
  - Criar virtualenv e instalar dependências:
    - python -m venv .venv
    - source .venv/bin/activate (Linux/Mac) ou .venv\Scripts\activate (Windows)
    - pip install -r requirements.txt
    - python main.py

- Web (HTML/CSS/JS)
  - Abrir index.html no navegador ou servir com Live Server / Vercel

- Banco de Dados
  - Importar scripts SQL em /database para criar schemas e sementes
