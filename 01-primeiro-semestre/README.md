# 📚 1º Semestre - Fundamentos de Programação

## 🎯 Objetivo

Introdução aos conceitos fundamentais de programação, com foco em lógica, estruturas de controle e manipulação de dados.

## 📖 Tópicos Cobertos

### Conceitos Básicos
- ✅ Variáveis e tipos de dados
- ✅ Operadores (aritméticos, lógicos, relacionais)
- ✅ Expressões e operações

### Estruturas de Controle
- ✅ Condicionais (if, else, switch)
- ✅ Laços (for, while, do-while)
- ✅ Fluxo de programa

### Funções e Modularização
- ✅ Declaração e chamada de funções
- ✅ Parâmetros e retorno
- ✅ Escopo de variáveis

### Estruturas de Dados
- ✅ Arrays e vetores
- ✅ Matrizes
- ✅ Manipulação de strings

## 💻 Linguagens Utilizadas

- **JavaScript** - Exercícios interativos
- **HTML/CSS** - Projetos web básicos
- **Java** - Fundamentos (opcional)

## 🚀 Como Executar

### Exercícios JavaScript
```bash
node nome-do-exercicio.js
```

### Projetos Web
```bash
# Opção 1: Abrir no navegador
open index.html

# Opção 2: Servir localmente
python -m http.server 8000
```
