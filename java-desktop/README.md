# Java Desktop

Esta pasta contém projetos de aplicações desktop desenvolvidas em Java (Swing) com arquitetura MVC e padrão DAO.  
O objetivo é demonstrar habilidades em POO, manipulação de banco de dados (MySQL) e construção de interfaces desktop.

Conteúdo
- Projeto: Sistema de Controle de Estoque
  - Local: /java-desktop/sistema-controle-estoque (se aplicável)
  - Tecnologias: Java, Swing, MySQL
  - Executar: instruções específicas por projeto (veja README do projeto)
