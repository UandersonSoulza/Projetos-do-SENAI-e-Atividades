# 🗄️ Documentação de Banco de Dados

## Bancos de Dados Implementados

### 1. controle_estoque
- **Descrição:** Sistema de gerenciamento de estoque
- **Tecnologia:** MySQL
- **Script:** `01-criacao-banco.sql`
- **Modelo:** `modelo-logico.xml`

### 2. portal_dados
- **Descrição:** Banco para portal de usuários
- **Tecnologia:** MySQL
- **Status:** Em desenvolvimento

### 3. vendas_sistema
- **Descrição:** Sistema de vendas integrado
- **Tecnologia:** MySQL
- **Status:** Em desenvolvimento

## 📖 Como Usar

1. Certifique-se de ter MySQL 5.7+ instalado
2. Execute o script: `mysql -u root -p < 01-criacao-banco.sql`
3. Configure as credenciais no seu projeto
