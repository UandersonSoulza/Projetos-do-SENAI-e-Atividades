# 📚 2º Semestre - Programação Orientada a Objetos

## 🎯 Objetivo

Dominare os princípios da Programação Orientada a Objetos (POO) e aplicá-los em projetos práticos.

## 📖 Tópicos Cobertos

### Fundamentos de POO
- ✅ Classes e Objetos
- ✅ Atributos e Métodos
- ✅ Encapsulamento (public, private, protected)
- ✅ Construtores e Destrutores

### Relacionamentos
- ✅ Herança
- ✅ Polimorfismo
- ✅ Interfaces e Classes Abstratas
- ✅ Composição vs Herança

### Conceitos Avançados
- ✅ Exceções e Tratamento de Erros
- ✅ Coleções (ArrayList, HashMap, HashSet)
- ✅ Padrões de Design (básicos)
- ✅ SOLID Principles (introdução)

## 💻 Linguagens Utilizadas

- **Java** - Principal linguagem (90%)
- **JavaScript** - Complementar (10%)

## 🚀 Como Executar

### Compilar projeto Java
```bash
cd projetos/biblioteca/
javac -d out src/**/*.java
java -cp out com.exemplo.Main
```

### Com Maven
```bash
mvn clean compile
mvn exec:java
```
