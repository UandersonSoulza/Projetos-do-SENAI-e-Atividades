# Python Desktop

Espaço para projetos em Python com interfaces gráficas e utilitários. Tecnologias previstas: CustomTkinter, Pillow (PIL) e automações com Python.

Este diretório pode conter:
- Aplicações completas com virtualenv e requirements.txt
- Scripts de automação e utilitários
- README por projeto com instruções de instalação e execução

Observação: se ainda não houver projetos, este README explica que a pasta está reservada para futuras adições.
